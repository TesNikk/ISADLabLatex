# Information Systems Analysis and Design - Chorcha EdTech Platform

## Overview

This repository contains the complete **Information Systems Analysis and Design (ISAD)** report for the Chorcha EdTech Platform project, developed as part of CSE 4110 coursework at Rajshahi University of Engineering & Technology (RUET).

## Project Details

- **Course:** CSE 4110 - Information Systems Analysis and Design Sessional
- **Section:** A
- **Academic Year:** 4th Year, 1st Semester
- **Institution:** Department of Computer Science & Engineering, RUET
- **Supervisor:** Dr. Md. Rabiul Islam, Professor

## Project Focus

**Chorcha EdTech Platform** - A comprehensive educational technology solution addressing the challenges faced by educational institutions in Rajshahi, with specific focus on:

- System scalability and performance optimization
- Progressive Web App (PWA) implementation for offline accessibility
- Load balancing and authentication system enhancements
- Low-bandwidth adaptation for rural connectivity

## Key System Solutions

1. **Load Balancing & Authentication Optimization** - Resolving system overload during peak usage
2. **Database Performance Enhancement** - Optimizing query performance and connection management
3. **PWA Offline Mode Implementation** - Enabling offline access for rural students with limited connectivity
